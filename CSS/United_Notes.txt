### **I. The Foundation: Web Trio & Development Environment**
*   **The Technology Stack:**
    *   **HTML:** The "skeleton" or "bricks/roof" providing the basic structure.
    *   **CSS:** The "paint," "makeup," and "styling" that adds beauty and layout.
    *   **JavaScript:** The "logic" (switches/fans) that dictates how things work.
*   **User Psychology in Design:** Brands use color strategically. **Red and Yellow** (e.g., McDonald's, Zomato, Coke) stimulate hunger and passion. **Blue** (e.g., PayPal, Paytm) conveys security and stability for banking.
*   **Professional Setup (VS Code):**
    *   **Emmet:** A built-in feature that uses abbreviations to generate long HTML/CSS code strings quickly.
    *   **Live Server/Chrome Inspect:** Essential for real-time debugging and visualizing the **Box Model**.

### **II. Level 1: CSS Syntax, Selectors, and Units**
*   **The CSS Rule:** Consists of a **Selector** (targets the element) and a **Declaration Block** containing **Property-Value pairs**. Statements must end with a **semicolon** (`;`) as a professional practice.
*   **Implementation Methods:**
    1.  **Inline:** Directly in the HTML tag via `style=""`. Highest priority.
    2.  **Internal:** Within `<style>` tags in the `<head>`. Useful for single-page styles.
    3.  **External (Professional Standard):** Linked via `<link rel="stylesheet" href="style.css">`. Promotes clean, manageable code.
*   **Selectors in Detail:**
    *   **Universal (`*`):** Targets every element; often used to reset margins/padding.
    *   **Element:** Targets tags directly (e.g., `h1`, `p`).
    *   **ID (`#idName`):** Unique to one element; higher priority than classes.
    *   **Class (`.className`):** Applied to multiple elements for group styling.
*   **Text Manipulation:**
    *   `text-align`: `left`, `right`, `center`, `start`, or `end` (important for multi-language support).
    *   `text-decoration`: Used to `none` out underlines on anchor tags or add `line-through`.
    *   `font-weight`: Range from **100** (lightest) to **900** (boldest); 400 is normal, 700 is bold.
    *   `text-transform`: `uppercase`, `lowercase`, `capitalize`.
*   **CSS Units:**
    *   **Absolute (px):** Fixed size. 1 inch = 96px.
    *   **Relative (%):** Percentage of the parent's width/height.
    *   **Relative (em/rem):** `em` is relative to the parent’s font; `rem` (Root em) is relative to the HTML root (usually 16px).

### **III. Level 2: The Box Model & Display Properties**
*   **The Box Model Anatomy:**
    *   **Content:** The innermost area where text/images reside.
    *   **Padding:** Space between content and border (internal).
    *   **Border:** The boundary; can be styled as `solid`, `dashed`, `dotted`, or `double`.
    *   **Margin:** Space between different boxes (external).
*   **Box Model Calculations:** Use `box-sizing: border-box` to ensure padding and borders are included in the element's total width/height, preventing layout breakage.
*   **Display Logic:**
    *   **Block:** Starts on a new line, takes full width (e.g., `div`, `h1`).
    *   **Inline:** Takes only necessary width; cannot have width/height set (e.g., `span`).
    *   **Inline-Block:** Stays in-line but allows width/height/margin/padding.
    *   **None vs. Hidden:** `display: none` removes the element and its space; `visibility: hidden` hides the element but keeps its space reserved.

---

### **IV. Level 3: Positioning, Layers, and Backgrounds**
*   **Positioning Values:**
    *   **Static:** Normal document flow (default).
    *   **Relative:** Positioned relative to itself; space is reserved.
    *   **Absolute:** Relative to the nearest *non-static* parent; removed from flow.
    *   **Fixed:** Glued to the browser viewport; doesn't move on scroll.
    *   **Sticky:** Switches from relative to fixed based on scroll position.
*   **Z-Index:** Controls the 3D stacking order along the Z-axis. Positive values bring items forward; negative values push them back.
*   **Background Handling:**
    *   `background-image`: Uses `url()` to link images.
    *   `background-size: cover`: Ensures the image fills the container without stretching.
    *   **Alpha Channel (RGBA):** The 'A' (0 to 1) controls **opacity**.

---

### **V. Level 4: Flexbox Mastery**
*   **Core Concepts:** Uses a **Flex Container** (Parent) and **Flex Items** (Children).
*   **Axes:** The **Main Axis** (default horizontal) and **Cross Axis** (default vertical).
*   **Parent Properties:**
    *   `flex-direction`: `row`, `column`, `row-reverse`, `column-reverse`.
    *   `justify-content`: Aligns items along the **Main Axis** (`center`, `flex-start`, `flex-end`, `space-evenly`, `space-between`).
    *   `align-items`: Aligns items along the **Cross Axis**.
    *   `flex-wrap`: Allows items to wrap into multiple lines if the container is too small.
*   **Child Properties:**
    *   `align-self`: Overrides the container's `align-items` for a single element.
    *   `flex-grow`: Defines how much an item should grow relative to others.
    *   `flex-shrink`: Defines how much an item should shrink when space is tight.

---

### **VI. Level 5: Transitions, Transforms, and Animations**
*   **Pseudo-classes:** `:hover` (when mouse is over) and `:active` (when clicked).
*   **Transitions:** Smoothly change properties over time. Syntax: `transition: [property] [duration] [timing-function] [delay]`.
*   **Transforms (2D/3D):**
    *   `rotate(deg)`: Spins elements.
    *   `scale(x, y)`: Resizes elements.
    *   `translate(x, y)`: Moves elements without affecting layout flow.
*   **Animations:**
    *   **@keyframes:** Defines the "From/To" or "0% to 100%" stages.
    *   **Properties:** `animation-name`, `duration`, `iteration-count` (`infinite`), and `direction` (`alternate`).
